# Combat Death Sound Candidates

Elegant / human medieval death cues. Copy a favorite over `../unit_death.wav` (or change the path in `lib/sound.ts` for `.mp3`).

| File | Source | Character |
| --- | --- | --- |
| `01_tinyworlds_die_gasp.ogg` | TinyWorlds / 5 Hit Sounds + Dying (CC0) | Soft RPG dying gasp. |
| `02_male_soft_exhale.wav` | remaxim / male pain voices (CC-BY 3.0) | **Current default.** Short male breath, restrained. |
| `03_character_short_gasp.mp3` | Badre-Eddine / hurt-death pack (CC0) | Very short character gasp (~0.3s). |
| `04_character_faint_fall.mp3` | Badre-Eddine / hurt-death pack (CC0) | Faint collapse exhale. |
| `05_character_quiet_death.mp3` | Badre-Eddine / hurt-death pack (CC0) | Quiet death breath. |
| `06_cloth_collapse.ogg` | Kenney RPG Audio (CC0) | Armor/cloth settle only — subtle, no voice. |
| `07_body_fall_heavy.ogg` | rubberduck / breaking-falling (CC0) | Heavy thud — too brutal for this game. |

All sources are free for game use. remaxim pack is CC-BY 3.0 (credit optional but appreciated).
